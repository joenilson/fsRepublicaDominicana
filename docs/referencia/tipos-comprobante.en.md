# Receipt types

Catalog preloaded in **Accounting → Dominican Republic → NCF types**.

![NCF types](../assets/img/ncf-tipos.png)

## Paper receipts (series B)

| Code | Description | Effect | Sales | Purchases | Taxpayers only |
|------|-------------|--------|:-----:|:---------:|:--------------:|
| 01 | Fiscal credit invoice | Adds | Yes | Yes | Yes |
| 02 | Consumer invoice | Adds | Yes | Yes | Yes |
| 03 | Debit note | Adds | Yes | Yes | No |
| 04 | Credit note | Subtracts | Yes | Yes | No |
| 11 | Purchases receipt | Adds | No | Yes | Yes |
| 12 | Single income register | Adds | Yes | No | No |
| 13 | Minor expenses receipt | Adds | No | Yes | No |
| 14 | Special regimes receipt | Adds | Yes | Yes | Yes |
| 15 | Government receipt | Adds | Yes | Yes | Yes |
| 16 | Export receipt | Adds | Yes | No | Yes |
| 17 | Payments abroad receipt | Adds | No | Yes | Yes |

| Code | Description | Effect | Sales | Purchases | Taxpayers only |
|------|-------------|--------|:-----:|:---------:|:--------------:|
| 31 | Electronic fiscal credit invoice | Adds | Yes | Yes | Yes |
| 32 | Electronic consumer invoice | Adds | Yes | Yes | Yes |
| 33 | Electronic debit note | Adds | Yes | Yes | No |
| 34 | Electronic credit note | Subtracts | Yes | Yes | No |
| 41 | Electronic purchases receipt | Adds | No | Yes | Yes |
| 43 | Electronic minor expenses receipt | Adds | No | Yes | No |
| 44 | Electronic special regimes receipt | Adds | Yes | Yes | Yes |
| 45 | Electronic government receipt | Adds | Yes | Yes | Yes |
| 46 | Electronic export receipt | Adds | Yes | Yes | Yes |
| 47 | Electronic payments abroad receipt | Adds | No | Yes | Yes |

!!! tip "Disable what you do not use"
    Each type has a **status**. Disable those your company does not issue so they do not show up in the invoice
    selector.
